  <name>Task 1: Migrate borrow, groups, and notifications actions to next-safe-action</name>
  <files>app/borrow/actions.ts, app/groups/actions.ts, app/notifications/actions.ts</files>
  <action>
Migrate all MUTATION actions in these 3 files to use next-safe-action. Leave QUERY actions (getActiveBorrows, getActiveBorrowsGroupedByContact, getUserGroups, getGroupDetails, getGroupByInviteCode, searchUsers, getNotifications, getUnreadNotificationCount, getPendingBorrowRequests, getPendingRequestsForItems) as-is.

**Follow the same migration pattern as Plan 02 Task 1:**
1. Replace function signature with `authActionClient.inputSchema(schema).action(async ({ parsedInput, ctx: { user, supabase } }) => { ... })`
2. Remove manual `createClient()` and `getUser()` calls from mutation bodies (use ctx)
3. Replace `return { error: msg }` with `throw new Error(msg)` for server errors
4. Keep success returns and revalidatePath calls

**Borrow actions (7 mutations):**
- `borrowItem`: authActionClient + borrowItemSchema. Destructure `{ itemId, groupId, startDate, dueDate, borrowerName }`. Keep redirect at end.
- `returnItem`: authActionClient + returnItemSchema. Destructure `{ recordId, itemId, groupId }`.
- `batchLendToContact`: authActionClient + batchLendToContactSchema. Destructure `{ itemIds, contactId, dueDate }`.
- `createBorrowRequest`: authActionClient + createBorrowRequestSchema. Destructure `{ itemId, contactId, dueDate, message }`.
- `acceptBorrowRequest`: authActionClient + acceptBorrowRequestSchema. Destructure `{ requestId }`.
- `rejectBorrowRequest`: authActionClient + rejectBorrowRequestSchema. Destructure `{ requestId, rejectionMessage }`.
- `getOrCreateContactForGroupMember`: authActionClient + getOrCreateContactForGroupMemberSchema. Destructure `{ groupMemberId, memberName, memberEmail }`.

**Groups actions (5 mutations):**
- `createGroup`: authActionClient + createGroupSchema. Destructure `{ name, description }`. Keep redirect at end. Note: current code uses `userData.user` -- simplify to `user` from ctx.
- `joinGroupByInviteCode`: authActionClient + joinGroupByInviteCodeSchema. Destructure `{ inviteCode }`.
- `regenerateInviteCode`: authActionClient + regenerateInviteCodeSchema. Destructure `{ groupId }`.
- `addItemsToGroup`: authActionClient + addItemsToGroupSchema. Destructure `{ groupId, itemIds }`.
- `addMembers`: authActionClient + addMembersSchema. Destructure `{ groupId, userIds }`.

**Notifications actions (4 mutations):**
- `markNotificationAsRead`: authActionClient + markNotificationAsReadSchema. Destructure `{ notificationId }`.
- `markAllNotificationsAsRead`: authActionClient with NO inputSchema (no input). Just `.action(async ({ ctx }) => { ... })`.
- `dismissNotification`: authActionClient + dismissNotificationSchema. Destructure `{ notificationId }`.
- `dismissAllNotifications`: authActionClient with NO inputSchema (no input).

Import schemas from colocated `./schemas` file. Import `authActionClient` from `@/lib/safe-action`.

IMPORTANT: Keep `'use server'` directive. Keep all query functions exactly as they are.
