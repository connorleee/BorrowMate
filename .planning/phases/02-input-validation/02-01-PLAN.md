  <name>Task 1: Install dependencies and create action client</name>
  <files>package.json, package-lock.json, lib/safe-action.ts</files>
  <action>
1. Run `npm install zod next-safe-action` to add both dependencies.

2. Create `lib/safe-action.ts` with two exports:

- `actionClient`: Base client for public actions (login, signup, signInWithGoogle). Uses `createSafeActionClient` with a `handleServerError` that returns `e.message`. Do NOT log to console (per Phase 1 decision -- errors propagated via return values only).

- `authActionClient`: Extends `actionClient` via `.use()` middleware. The middleware calls `createClient()` from `@/utils/supabase/server`, then `supabase.auth.getUser()`. If error or no user, throws `new Error("Not authenticated")`. On success, passes `{ user, supabase }` in context via `next({ ctx: { user, supabase } })`.

Follow exact pattern from 02-RESEARCH.md "Pattern 1: Action Client with Auth Middleware". Import types as needed for TypeScript strict mode compatibility.
  </action>

- `npm ls zod next-safe-action` shows both installed
- `npx tsc --noEmit lib/safe-action.ts` compiles without errors (or run full `npm run build` if easier)
  </verify>
  <done>
- zod and next-safe-action in package.json dependencies
- lib/safe-action.ts exports actionClient and authActionClient
- TypeScript compiles cleanly
  </done>

  <action>
Create a `schemas.ts` file in each domain directory that has mutation actions, colocated with the existing `actions.ts`. Each schema must match the CURRENT input signature of its action function exactly. Read the action file to confirm field names and types.

Note: `app/users/actions.ts` contains only query functions (getUserProfile, getUserPublicItems) — all follow-related mutations were removed in Phase 1. No schemas.ts is needed for the users domain.

**app/auth/schemas.ts:**
- `loginSchema`: `{ email: z.string().email(), password: z.string().min(1, "Password is required") }`
- `signupSchema`: `{ name: z.string().min(1, "Name is required").max(100), email: z.string().email(), password: z.string().min(8, "Password must be at least 8 characters") }`
- `signInWithGoogleSchema`: empty object `z.object({})` (no meaningful input -- the FormData is unused)

**app/items/schemas.ts:**
- `createItemSchema`: `{ name: z.string().min(1).max(255), description: z.string().max(1000).optional().default(""), category: z.string().max(100).optional().default(""), privacy: z.enum(["private", "public"]).default("private"), groupId: z.string().uuid().nullable().optional() }`
- `deleteItemSchema`: `{ itemId: z.string().uuid("Invalid item ID") }`
- `updateItemSchema`: `{ itemId: z.string().uuid(), name: z.string().min(1).max(255).optional(), description: z.string().max(1000).optional(), category: z.string().max(100).optional(), price_usd: z.number().min(0).optional() }`

**app/contacts/schemas.ts:**
- `createContactSchema`: `{ name: z.string().min(1, "Contact name is required").max(255), email: z.string().email().nullable().optional(), phone: z.string().max(50).nullable().optional() }`
- `updateContactSchema`: `{ contactId: z.string().uuid(), name: z.string().min(1, "Contact name is required").max(255), email: z.string().email().nullable().optional(), phone: z.string().max(50).nullable().optional() }`
- `deleteContactSchema`: `{ contactId: z.string().uuid() }`
- `linkContactToUserSchema`: `{ contactId: z.string().uuid(), userId: z.string().uuid() }`

**app/borrow/schemas.ts:**
- `borrowItemSchema`: `{ itemId: z.string().uuid(), groupId: z.string().uuid(), startDate: z.string().min(1), dueDate: z.string().optional(), borrowerName: z.string().optional() }`
- `returnItemSchema`: `{ recordId: z.string().uuid(), itemId: z.string().uuid(), groupId: z.string() }` (groupId can be empty string -- used for revalidation only)
- `batchLendToContactSchema`: `{ itemIds: z.array(z.string().uuid()).min(1, "Select at least one item"), contactId: z.string().uuid(), dueDate: z.string().optional() }`
- `createBorrowRequestSchema`: `{ itemId: z.string().uuid(), contactId: z.string().uuid(), dueDate: z.string().optional(), message: z.string().max(500).optional() }`
- `acceptBorrowRequestSchema`: `{ requestId: z.string().uuid() }`
- `rejectBorrowRequestSchema`: `{ requestId: z.string().uuid(), rejectionMessage: z.string().max(500).optional() }`
- `getOrCreateContactForGroupMemberSchema`: `{ groupMemberId: z.string().uuid(), memberName: z.string().optional(), memberEmail: z.string().email().optional() }`

**app/groups/schemas.ts:**
- `createGroupSchema`: `{ name: z.string().min(1, "Group name is required").max(255), description: z.string().max(1000).optional().default("") }`
- `joinGroupByInviteCodeSchema`: `{ inviteCode: z.string().min(1, "Invite code is required") }`
- `regenerateInviteCodeSchema`: `{ groupId: z.string().uuid() }`
- `addItemsToGroupSchema`: `{ groupId: z.string().uuid(), itemIds: z.array(z.string().uuid()).min(1) }`
- `addMembersSchema`: `{ groupId: z.string().uuid(), userIds: z.array(z.string().uuid()).min(1) }`

**app/notifications/schemas.ts:**
- `markNotificationAsReadSchema`: `{ notificationId: z.string().uuid() }`
- `dismissNotificationSchema`: `{ notificationId: z.string().uuid() }`
(markAllNotificationsAsRead and dismissAllNotifications take no input -- they only need authActionClient wrapping with no schema.)

Each file should `import { z } from "zod"` and export all schemas as named exports. Use descriptive validation error messages for user-facing fields (name, email, password). Use simple defaults for non-critical fields.
