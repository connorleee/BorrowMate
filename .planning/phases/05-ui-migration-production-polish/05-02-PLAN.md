**Card.tsx domain components migration:**
Migrate the internal implementation of `Card.tsx`'s domain card components (`ItemCard`, `ContactCard`, `GroupCard`, `BorrowRecordCard`) to use `Card` and `Badge` from `@/components/ui` internally. Keep the existing prop APIs unchanged so consumer code does not break.

- Replace manual card styling (`className="card ..."` or `bg-white dark:bg-gray-800 border ...`) with `<Card>` from ui
- Replace `.badge-success`, `.badge-error`, `.badge-warning` CSS classes with `<Badge variant="success">` etc. from ui
- Replace hardcoded text colors (`text-gray-600`, `text-gray-500`) with CSS variable classes (`text-[var(--text-secondary)]`, `text-[var(--text-tertiary)]`)
- Remove all `dark:` override classes that are now handled by CSS variables
- Keep the base `Card` export in Card.tsx — it should now just re-export or wrap the ui/Card

**Navigation components migration:**
For `Sidebar.tsx`, `SidebarClientContent.tsx`, `TopNav.tsx`, `ThemeToggle.tsx`:

Apply the color mapping from RESEARCH.md:
- `bg-white` → `bg-[var(--bg-base)]`
- `bg-gray-50` → `bg-[var(--bg-surface)]`
- `bg-gray-100/200` → `bg-[var(--bg-elevated)]`
- `text-gray-900/700` → `text-[var(--text-primary)]`
- `text-gray-600/500` → `text-[var(--text-secondary)]`
- `text-gray-400/300` → `text-[var(--text-tertiary)]`
- `border-gray-200/300` → `border-[var(--border)]`
- `hover:bg-gray-50` → `hover:bg-[var(--bg-surface)]`
- `hover:bg-gray-100/200` → `hover:bg-[var(--bg-elevated)]`
- Remove ALL corresponding `dark:bg-gray-*`, `dark:text-gray-*`, `dark:border-gray-*` from the same elements

Replace any raw `<button>` elements with `Button` from `@/components/ui` where appropriate (unless the button has very custom styling like nav links that don't map to Button variants).

Use the frontend-design skill to ensure navigation components look polished after migration.
