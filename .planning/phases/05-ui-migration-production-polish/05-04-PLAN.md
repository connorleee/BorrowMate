**Toast integration — for each component that calls a mutation server action:**

Import `useToast` from `@/components/toast-provider` and call `addToast()` after each mutation:

| Component | Action(s) | Toast Message |
|-----------|-----------|---------------|
| `add-item-form.tsx` | createItem | success: "Item added successfully" / error: serverError message |
| `delete-item-button.tsx` | deleteItem | success: "Item deleted" / error: serverError message |
| `add-contact-modal.tsx` | createContact | success: "Contact added" / error: serverError message |
| `contact-list-section.tsx` | deleteContact | success: "Contact deleted" / error: serverError message |
| `contact-detail-content.tsx` | returnItem, linkContactToUser | success: "Item returned" / "Contact linked" / error: serverError |
| `batch-lend-modal.tsx` | batchLendToContact | success: "Items lent successfully" / error: serverError message |
| `borrow-request-modal.tsx` | borrowItem, acceptBorrowRequest, rejectBorrowRequest | success/error for each |
| `item-detail-modal.tsx` | updateItem | success: "Item updated" / error: serverError message |
| `invite-user-modal.tsx` | inviteUserToGroup (if exists) | success/error |
| `lend-to-contact-modal.tsx` | lendToContact (if applicable) | success/error |
| `my-inventory-section.tsx` | any lending actions | success/error |

Pattern for each:
```typescript
const { addToast } = useToast()
// After calling action:
if (result?.serverError) {
  addToast('error', result.serverError)
} else {
  addToast('success', 'Item added successfully')
}
```

**Important:** For mutations (create, update, delete, lend, return), use toast notifications. Remove any existing inline success/error message divs that duplicate the toast feedback. Keep field-level validation errors inline (those are not toasts).
