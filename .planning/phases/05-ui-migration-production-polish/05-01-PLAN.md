  <action>
Create `components/toast-provider.tsx` — a client component implementing:
- React Context with `useToast()` hook exposing `addToast(type: 'success' | 'error', message: string)`
- Toast state as array of `{ id, type, message }` objects
- Max 3 toasts visible at once — when adding a 4th, oldest is removed (slice from end)
- Success toasts auto-dismiss after 3000ms via setTimeout
- Error toasts auto-dismiss after 6000ms via setTimeout
- Error toasts include a dismiss "X" button
- Portal renders toasts to document.body at bottom-center using `fixed bottom-6 left-1/2 -translate-x-1/2 z-[60]`
- Use CSS variable classes for colors: success uses `bg-success-50 text-success-800 border-success-200` (and dark: variants for palette shifts), error uses `bg-error-50 text-error-800 border-error-200` (and dark: variants)
- Guard `createPortal` with `typeof document !== 'undefined'` check
- Use the frontend-design skill for polished toast design — toasts should have subtle entry animation, rounded corners, shadow, and feel distinctive/production-grade

Create `components/empty-state.tsx` — a client component implementing:
- Props: `message: string`, `ctaLabel: string`, `ctaHref?: string`, `onCtaClick?: () => void`
- Renders centered text + CTA button in a dashed-border container
- Uses CSS variable classes: `text-[var(--text-secondary)]`, `border-[var(--border)]`
- CTA uses `Button` from `@/components/ui` with variant="primary"
- If `ctaHref` provided, wrap Button in `<a>` link. If `onCtaClick`, use onClick.
- Tone should be friendly per user decision: designed for messages like "No items yet — add your first one!"
- Use the frontend-design skill for polished empty state design
