  <name>Task 1: Install dependencies, create cn() utility, and enhance design tokens</name>
  <files>package.json, lib/utils.ts, app/globals.css</files>
  <action>
1. Install the three libraries:
   ```bash
   npm install class-variance-authority clsx tailwind-merge
   ```
   Ensure tailwind-merge resolves to v3.x (required for Tailwind CSS v4 compatibility).

2. Create `lib/utils.ts` with the cn() utility:
   ```typescript
   import { clsx, type ClassValue } from "clsx"
   import { twMerge } from "tailwind-merge"

   export function cn(...inputs: ClassValue[]) {
     return twMerge(clsx(inputs))
   }
   ```

3. Enhance `app/globals.css` design tokens. Add documentation comments for the project's spacing and typography conventions BELOW the existing `[data-theme="dark"]` block but ABOVE the existing utility classes. Do NOT modify any existing CSS classes or @theme tokens -- only add comments. Add:

    *   gap-3 (12px) - Compact spacing (list items)
    *   gap-4 (16px) - Standard spacing (form fields, card content)

<task type="auto">
  <name>Task 2: Build Button and Input primitive components</name>
  <files>components/ui/button.tsx, components/ui/input.tsx</files>
  <action>
1. Create directory `components/ui/` if it does not exist.

2. Create `components/ui/button.tsx`:
   - Use CVA with the following variants:
     - `variant`: primary (bg-primary-500, white text, hover:bg-primary-600), secondary (border + bg-surface CSS var, hover:bg-elevated), destructive (bg-error-500, white text, hover:bg-error-600), ghost (transparent, hover:bg-surface CSS var)
     - `size`: sm (text-sm px-3 py-1.5), md (text-sm px-4 py-2), lg (text-base px-5 py-2.5)
     - `defaultVariants`: variant: "primary", size: "md"
   - Base classes: inline-flex items-center justify-center rounded-lg font-medium transition-colors focus:outline-none focus:ring-2 focus:ring-offset-2 disabled:opacity-50 disabled:cursor-not-allowed
   - Extend `React.ButtonHTMLAttributes<HTMLButtonElement>` and `VariantProps<typeof buttonVariants>`
   - Accept and merge `className` prop via cn() (className goes LAST so consumer overrides win)
   - Export both `Button` component and `buttonVariants` (secondary export for Link-as-button use case)
   - Use CSS custom properties for theme-aware colors: `bg-[var(--bg-surface)]`, `text-[var(--text-primary)]`, `border-[var(--border)]`, etc.
   - Use @theme palette tokens for fixed colors: `bg-primary-500`, `bg-error-500`, etc.

3. Create `components/ui/input.tsx`:
   - Use CVA with the following variants:
     - `inputSize`: sm (px-2.5 py-1.5 text-sm), md (px-3 py-2 text-sm), lg (p-3 text-base)
     - `error`: true (border-error-500 focus:ring-error-500), false (border-[var(--border)] focus:ring-primary-500)
     - `defaultVariants`: inputSize: "md", error: false
   - Base classes: w-full rounded-lg border transition-colors focus:outline-none focus:ring-2 focus:border-transparent disabled:opacity-50 disabled:cursor-not-allowed bg-[var(--bg-base)] text-[var(--text-primary)]
   - IMPORTANT: Name the size variant `inputSize` (not `size`) to avoid collision with the HTML `size` attribute. Omit `size` from the extended HTMLInputElement attributes using `Omit<React.InputHTMLAttributes<HTMLInputElement>, "size">`.
   - Props: `label?: string`, `errorMessage?: string`, `id?: string` in addition to CVA variants and HTML input attributes
   - If `label` is provided, render a `<label>` element above the input with `htmlFor` linked to the input's id
   - If `errorMessage` is provided, render a `<p>` with `text-sm text-error-500` below the input AND force the error variant to true
   - Auto-generate id from label text if no explicit id provided: `label?.toLowerCase().replace(/\s+/g, "-")`
   - Wrap in a `<div className="space-y-1">` container
   - Accept and merge `className` on the input element via cn()

Both components must NOT use `forwardRef` (React 19 supports ref-as-prop, and the project does not currently need refs on these primitives -- per research Pitfall 6).
  </action>
