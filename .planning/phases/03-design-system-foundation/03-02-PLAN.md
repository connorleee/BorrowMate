<task type="auto">
  <name>Task 2: Build Modal primitive and create barrel export</name>
  <files>components/ui/modal.tsx, components/ui/index.ts</files>
  <action>
1. Create `components/ui/modal.tsx`:
   - Mark as `"use client"` at the top of the file (uses createPortal, useEffect, useCallback)
   - Props interface `ModalProps`: `isOpen: boolean`, `onClose: () => void`, `children: React.ReactNode`, `className?: string`, `size?: "sm" | "md" | "lg"`
   - Default size: "md"
   - Size classes mapping: sm = "max-w-sm", md = "max-w-lg", lg = "max-w-2xl"
   - Implement escape key handler:
     ```typescript
     const handleEscape = useCallback((e: KeyboardEvent) => {
       if (e.key === "Escape") onClose()
     }, [onClose])
     ```
   - useEffect that runs when `isOpen` changes:
     - When open: add keydown listener for escape, set `document.body.style.overflow = "hidden"` (body scroll lock per research Pitfall 5)
     - Cleanup: remove keydown listener, restore `document.body.style.overflow = ""`
   - Early return if `!isOpen` or `typeof document === "undefined"` (server-safe per CLAUDE.md patterns)
   - Render via `createPortal` to `document.body`:
     - Overlay: `fixed inset-0 z-50 flex items-center justify-center bg-black/50 backdrop-blur-sm p-4`
     - Click-outside: `onClick` on overlay div checks `e.target === e.currentTarget` before calling `onClose`
     - Content wrapper: `bg-[var(--bg-base)] rounded-xl shadow-xl w-full max-h-[85vh] flex flex-col overflow-hidden` + size class + consumer className via cn()
   - Create composable sub-components (all accept className via cn()):
     - `ModalHeader`: `p-4 border-b border-[var(--border)]` -- renders children in a div
     - `ModalBody`: `flex-1 overflow-y-auto p-4` -- renders children in a scrollable div
     - `ModalFooter`: `p-4 border-t border-[var(--border)] bg-[var(--bg-surface)]` -- renders children in a div
   - Export: `Modal`, `ModalHeader`, `ModalBody`, `ModalFooter`
   - Do NOT use `bg-white` or hardcoded dark mode colors -- use CSS custom properties exclusively

2. Create `components/ui/index.ts` barrel export:
   ```typescript
   export { Button, buttonVariants } from "./button"
   export type { ButtonProps } from "./button"
   export { Input } from "./input"
   export type { InputProps } from "./input"
   export { Card } from "./card"
   export { Badge, badgeVariants } from "./badge"
   export type { BadgeProps } from "./badge"
   export { Modal, ModalHeader, ModalBody, ModalFooter } from "./modal"
   ```
   Note: This barrel export enables `import { Button, Card, Badge } from "@/components/ui"` for Phase 5 migration convenience.
