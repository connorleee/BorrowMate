  <action>
Update `next.config.ts` to add security headers using the native Next.js `headers()` async function. The current file is minimal (empty config object).

Add the following headers applied to all routes via `source: "/(.*)"`:

1. **Content-Security-Policy** built from an array of directives joined with "; ":
   - `default-src 'self'`
   - `script-src 'self' 'unsafe-inline'` (add `'unsafe-eval'` only when `process.env.NODE_ENV === 'development'` for Next.js HMR)
   - `style-src 'self' 'unsafe-inline'`
   - `img-src 'self' blob: data:`
   - `font-src 'self'`
   - `object-src 'none'`
   - `base-uri 'self'`
   - `form-action 'self'`
   - `frame-ancestors 'none'` (replaces X-Frame-Options in modern browsers)
   - `connect-src 'self' ${supabaseUrl} wss://*.supabase.co` where `supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL ?? ""`
   - `upgrade-insecure-requests`

2. **X-Frame-Options**: `DENY` (legacy browser fallback for frame-ancestors)

3. **X-Content-Type-Options**: `nosniff`

4. **Referrer-Policy**: `origin-when-cross-origin`

Implementation notes:
- Use `const isDev = process.env.NODE_ENV === "development"` for conditional eval
- Use `const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL ?? ""` for Supabase connect-src
- Build CSP as array of strings, join with "; " for readability
- Keep the existing `NextConfig` type import
- Do NOT use nonces (requires dynamic rendering on all pages -- unnecessary complexity per research)
